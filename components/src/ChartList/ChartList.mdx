# ChartList

**Development-only** utility component for displaying a list of charts with associated embed, typically at the `/` route of your Svelte project.

## Usage

In your `+page.svelte`:

```js
<script>
  import { ChartList, DesignTokens } from '@swr-data-lab/components';

  const charts = [
    { title: 'Baden-Württemberg Loosers', url: 'https://static.datenhub.net/apps/p110_wald-klimawandel/main/bw-loosers.html' },
    { title: 'Baden-Württemberg Winners', url: 'https://static.datenhub.net/apps/p110_wald-klimawandel/main/bw-winners.html' },
    { title: 'Rheinland-Pfalz Loosers', url: 'https://static.datenhub.net/apps/p110_wald-klimawandel/main/rp-loosers.html' },
    { title: 'Rheinland-Pfalz Winners', url: 'https://static.datenhub.net/apps/p110_wald-klimawandel/main/rp-winners.html' }
  ];
</script>

<DesignTokens>
  <ChartList {charts} project="p110: Wie sieht der Wald von morgen aus?" />
</DesignTokens>
```

### Props

- `charts` is a list of `ChartSpec` objects of the following shape:

  ```ts
  interface ChartSpec {
  	title: string;
  	url: string;           // Full chart URL (preferred)
  	group?: string;        // Optional grouping key
  	slug?: string;         // @deprecated Use `url` instead
  }
  ```

- `project` is a string of the shape `<Project Number>: <Project Title>`.
- `group` is an optional group name (useful for grouping charts by bundesland).
- `baseUrl` is **deprecated** — provide a full per-chart `url` instead.
